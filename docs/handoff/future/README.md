# Future registry

`FUTURE_CONSIDERATIONS.yaml` is the authoritative prerequisite/revisit registry for compatible ideas outside V1 CORE. `FUTURE_CONSIDERATIONS.md` is its readable rendering.

Ideas moved into V1 in v4.2 (minimal knowledge, instruction/reference Skills, deterministic AuditService, basic Inference Resource Manager) are no longer deferred. Their advanced variants remain here.

ANL/ASM remain historical/superseded and are intentionally not future candidates because they conflict with Event Contracts.
